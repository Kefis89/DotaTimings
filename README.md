# Таймер рун Dota 2

Одностраничное веб-приложение: таймеры рун, святилищ мудрости, Торментора и смены дня/ночи.
Работает в браузере, ставится на домашний экран телефона и работает офлайн.

## Файлы
- `index.html` — всё приложение
- `sounds/*.wav` — звуки оповещений (генерируются `tools/make_sounds.py`)
- `manifest.json`, `icon-192.png`, `icon-512.png` — установка на домашний экран
- `sw.js` — офлайн-режим

## Тайминги
Расписание событий лежит в массиве `EVENTS` в начале скрипта в `index.html`.
После изменения файлов увеличь версию `CACHE` в `sw.js` (например, `dota-timer-v2`).
